# Обработка изображений

Sharp работает только на сервере Node.js. Сервис проверяет формат и
содержимое JPEG, PNG и WebP, размер и предел 40 мегапикселей, отклоняет
анимированные и повреждённые изображения, применяет EXIF-ориентацию и
сохраняет WebP без EXIF/GPS. Изображения не увеличиваются.

Параметры `IMAGE_*` из `.env.example` реально используются; некорректные
значения вызывают ошибку конфигурации. Верхние пределы: 20 фотографий,
10 МиБ исходник, максимальная сторона 1920 px, аватар 5 МиБ / 256 px.
Ширины должны удовлетворять thumbnail ≤ catalog ≤ gallery.

| Вариант | Размер по умолчанию | Качество | Назначение |
|---|---:|---:|---|
| thumbnail | до 320 px | 75 | небольшие превью |
| catalog | до 640 px | 80 | карточки |
| gallery | до 1920 px | 82 | галерея |
| avatar | до 256 × 256 px, cover | 85 | аватар |

Маленький аватар может быть меньше 256 × 256: увеличение запрещено.
Локальный путь сохраняет gallery; Blob-путь создаёт три варианта фотографии.
Одновременно в одном процессе обрабатываются не более двух изображений;
это не распределённая квота между serverless-инстансами.

Локальные измерения gallery-WebP для трёх исходников:

| Файл | До, байт | После, байт | Уменьшение |
|---|---:|---:|---:|
| BMW_3_Series.png | 2 129 395 | 113 418 | 94,67% |
| Audi_A4.png | 5 123 713 | 298 560 | 94,17% |
| Volkswagen_Golf.png | 5 296 855 | 310 308 | 94,14% |

Это результаты для конкретных файлов, а не гарантия сжатия. Они не включают
размер остальных вариантов и не являются данными биллинга Vercel. Реальный
Blob и браузерную прямую загрузку нужно проверять отдельно.
