# План тестирования — промежуточное состояние

1. PASSED частично: инвентаризация, изолированная БД, сборка и типы.
2. PASSED частично: фильтры, авторизация, отдельные API и покупатель в UI.
3. PASSED частично: черновик с фото, отклонение и повторная отправка,
   одобрение и архивирование через UI. NOT TESTED: остальные страницы и
   крайние случаи продавца и модерации.
4. PASSED частично: три браузерных движка, размеры экрана, axe и один
   клавиатурный сценарий. NOT TESTED: полная ручная доступность и screen reader.
5. PASSED частично: лабораторный Lighthouse и короткие нагрузочные всплески.
   NOT TESTED: долговременная нагрузка и production.
6. PASSED: lint без ошибок, остаются предупреждения форматирования.
   FAILED: одна подтверждённая валютная несогласованность.
7. PASSED частично: покрытие файлов auth unit-тестов. NOT TESTED: общее
   покрытие проекта и API; итоговый аудит ещё требуется.

Все изменяющие и нагрузочные проверки запускать только на изолированной
тестовой среде. Детали и результаты — в остальных отчётах.
