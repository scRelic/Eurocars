# Карта проекта — промежуточный аудит

- Nuxt 4, Vue 3, TypeScript, PostgreSQL; 26 файлов страниц и 53 файла API.
- Публичные маршруты: главная, каталог, карточка автомобиля, вход,
  регистрация и восстановление пароля; также профиль и создание объявления.
- Кабинет: объявления, редактирование, избранное, сообщения, уведомления,
  настройки профиля и безопасности. Админка: объявления, модерация,
  пользователи, дилеры, журнал и настройки.
- API сгруппированы по auth, cars, favorites, conversations, notifications,
  users, admin, brands и справочникам; перечень методов приведён в README.
- При аудите схема `server/db.sql` содержала 17 таблиц и миграции 001–006.
  Позднее добавлены две таблицы для незавершённой интеграции изображений и
  отдельная миграция 007; она не применялась к рабочей базе.
- Восстановление пароля и редактируемые постоянные настройки администратора:
  NOT IMPLEMENTED. Перечень обнаруженных проблем — в `BUG_REPORT.md`.
- Карта является инвентаризацией, не подтверждением работы каждой страницы
  или каждого API.
