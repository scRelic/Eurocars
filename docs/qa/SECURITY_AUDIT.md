# Аудит безопасности — промежуточный результат

## Зависимости

- `npm audit` и `npm audit --omit=dev`: FAILED, по 8 записей moderate,
  без high и critical, на момент проверки 2026-11-24.
- Прямое предупреждение относится к транзитивному `minimatch` 10.2.6
  через `nuxt` → `@nuxt/nitro-server` → `nitropack` → `archiver` →
  `readdir-glob`: [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249).
  Остальные записи отражают цепочку зависимостей.
- Влияние на развёрнутое приложение и возможность эксплуатации не
  подтверждены. Предложенный npm вариант меняет версию Nuxt на 4.6.3;
  автоматический `audit fix --force` не запускался.
- Статус: FAILED; выбрать совместимое обновление после проверки зависимостей.

## Проверки приложения

- Интеграционный тест проверяет часть разграничения прав, приватность фото,
  сообщения, модерацию, проверки входа и загрузку файлов: PASSED.
- PASSED: выборочные проверки Origin/CSRF, атрибутов cookie, rate limit,
  ротации и отзыва сессий, а также экранирования HTML в названии объявления.
- PASSED: браузерные проверки перенаправления гостя и обычного пользователя
  с админки и отказа admin API (401/403) в трёх движках.
- PASSED: непубличные объявления DRAFT, PENDING, SOLD, REJECTED и ARCHIVED
  возвращают 404 на публичной странице и API для всех проверенных ролей.
  Доступ через отдельные API владельца и администратора ограничен ролью;
  приватность фото проверена для DRAFT, SOLD и ARCHIVED.
- PASSED: конкурентная регистрация одного email создаёт только одну учётную
  запись; проверен один SQL-injection-подобный ввод. Это не полный аудит
  инъекций или конкурентных операций.
- Полный security review, проверка всех API и ручное тестирование
  атак: NOT TESTED. Оценивать проект как безопасный на этом основании нельзя.
