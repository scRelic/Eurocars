Дата: 2026-11-24.

## Текущий этап

используется отдельный временный PostgreSQL-кластер.

## Обнаруженные ограничения

- Функциональность восстановления пароля отсутствует; её реализация требует
  согласования новой бизнес-логики и инфраструктуры отправки писем.
- Остались 27 предупреждений форматирования ESLint.
- На Windows генерация ESLint-конфига в копии с `node_modules`-junction на
  другой диск сформировала неверные импорты; проверка успешно запустилась
  после установки зависимостей непосредственно в изолированной копии.
- Рабочая БД и пользовательские данные не изменялись. Production build
  выполнен в отдельной копии; существующая `.output` проекта не обновлялась.
